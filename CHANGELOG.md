# Changelog

All notable changes to the Technicolor themes are documented in this file. The
format is based on [Keep a Changelog](https://keepachangelog.com/).

## 0.2.0 - 2026-08-09

### Added

- **Technicolor Silent Era** — an eighth, monochrome variant. Silver-gray
  ramp on a warm near-black base, bold keywords, muted functional colors for
  diagnostics and diffs.

### Changed

- 88 new workbench color keys in every variant: suggest-widget symbol icons,
  notebooks, chat and inline chat, toolbars, quick picker groups, the search
  editor, extension views, problems icons, marker navigation, and ports. All
  variants still define the identical key set (now 455 keys).
- Drive-In backgrounds carry a cooler night-sky cast instead of neutral gray.
- Extension icon and banner now show eight bars.
- Token rule names are identical across all variants; Drive-In, Kodachrome,
  and Psychedelic used abbreviated names for some rules.

## 0.1.1 - 2026-07-06

### Changed

- All seven themes now define the same set of workbench colors, so menus,
  settings, charts, and debug icons are themed consistently in every variant.
- Markdown headings are now colored in all variants.

### Fixed

- Drive-In status bar text was too dim; it now matches the editor foreground.

## 0.1.0 - 2026-06-25

### Added

- Initial public release with seven dark themes:
  - **Technicolor Neon** — 80s cyberpunk / synthwave (flagship)
  - **Technicolor Deep** — neo-noir blue-purple atmosphere
  - **Technicolor Warm** — golden-hour earthy retro tones
  - **Technicolor Kodachrome** — vintage film stock
  - **Technicolor Drive-In** — 1950s Americana
  - **Technicolor Psychedelic** — 1960s counterculture
  - **Technicolor Marquee** — classic Hollywood marquee lights
