# Technicolor

A set of seven dark themes for VS Code, each tuned to a specific era and mood.

## Themes

| Theme | Inspiration |
|-------|-------------|
| Neon | 80s cyberpunk and synthwave |
| Deep | Neo-noir, late nights |
| Warm | Golden-hour cinematography |
| Kodachrome | Vintage film stock |
| Drive-In | 1950s Americana |
| Psychedelic | 1960s counterculture |
| Marquee | Classic Hollywood marquee lights |

## Install

```bash
git clone https://github.com/JazzJackrabbit/technicolor-vscode.git \
  ~/.vscode/extensions/technicolor-vscode
```

Restart VS Code, then run **Preferences: Color Theme** and select a Technicolor variant.
